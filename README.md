# MSCS-tracker

A responsive single-page milestone tracker for the CU Boulder MS in Computer
Science and Professional MS in Computer Science degrees.

## Files

- `index.html` contains the app layout and page structure.
- `styles.css` contains the responsive visual design.
- `data.js` contains the course lists, official links, and FAQ copy.
- `script.js` powers the pathway logic, credit totals, and deadlines.
